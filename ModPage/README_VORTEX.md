[size=4][b]About This Release[/b][/size]
Abiotic Loader is a standalone Abiotic Factor launcher and mod-management tool.
It is designed to help with launching the game, managing mod folders, checking UE4SS, and keeping the current workflow organized in a desktop-style interface.

[size=4][b]What Is Included[/b][/size]
[list]
[*]Current executable build
[*]Required assets
[*]Source folder for reference and future development
[*]Early-access settings and update flow
[*]Mod browser and mod manager screens
[/list]

[size=4][b]Install[/b][/size]
[list=1]
[*]Download the release zip.
[*]Extract it to a folder you want to keep the loader in.
[*]Keep the folder structure intact.
[*]Run [b]Abiotic_Loader.exe[/b].
[*]Open [b]Settings[/b] and set the Abiotic Factor install path if it is not detected automatically.
[/list]

[size=4][b]Vortex Notes[/b][/size]
This is [b]not[/b] a Vortex plugin.
It is a standalone loader that can sit alongside your normal Vortex workflow if you want a separate Abiotic Factor launcher and mod manager.

[size=4][b]Troubleshooting[/b][/size]
[list]
[*]Make sure the zip was fully extracted.
[*]Do not separate the executable from the packaged folder structure.
[*]Verify the Abiotic Factor install path in Settings.
[*]Refresh the app after changing mod folder contents.
[*]If the loader cannot find the game, manually set [b]AbioticFactor-Win64-Shipping.exe[/b] from Settings.
[/list]
