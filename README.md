# Abiotic Loader v0.3

**Early Access Notice**
This build is early access and not finished yet.
It is intentionally being shared before the project is complete so testers can try the current UI, packaging flow, and mod management features.
Expect rough edges, missing polish, unfinished behavior, and changes between releases.

## What You Are Getting
Abiotic Loader is a custom launcher and mod manager for Abiotic Factor.
This release includes the current app build, the assets it needs to run, and the source code folder for reference and development.
The source is included in the packaged release so the project can be inspected, reviewed, or rebuilt later.

## How To Install
1. Download or extract the release zip.
2. Keep the folder structure intact.
3. Run `Abiotic_Loader.exe` from the main release folder.
4. If the game path is not detected automatically, open Settings and choose `AbioticFactor-Win64-Shipping.exe`.

## What The Loader Does Right Now
- Launches Abiotic Factor from the desktop-style main menu.
- Opens the UE4SS manager page for patching and update checks.
- Opens the mod manager page for browsing, applying, disabling, and refreshing mod packages.
- Saves basic warnings and preferences between launches.
- Supports the current early-access UI layout and release workflow.

## Important Early Access Notes
- This is not a finished public release.
- Some buttons, screens, and labels may still change.
- Mod handling and update checks are still being refined.
- The release is intended for testing, feedback, and iterative improvement.
- If something looks unfinished, that is expected in this build.

## Source Included
A `Source` folder is included with the release for convenience.
It contains the current project files used to build the launcher.
If you only want to run the app, you can ignore the source folder.
If you want to inspect or modify the project, the source is already bundled here.

## Support / Feedback
If you use this build and find a bug, the most useful feedback is:
- what screen you were on
- what button you clicked
- what you expected to happen
- what actually happened

That helps keep the next release focused and easier to improve.
